# Boreviax Ledger V15

Boreviax Materials Inc. 内部财务账本。此版本是可安装的 PWA：部署到 Vercel 后，可从 Chrome 或 Edge 安装到 Windows 或 macOS 桌面，以独立窗口运行。

## 已完成功能

- 首次联网登录并加载数据后，断网也能直接打开账本。
- 采购账、客户来款、投资款、公私户互转、费用均支持离线新增、修改、删除和查询。
- 采购账不再显示税款，新增手续费及付款账户（公户/私户）。
- 客户来款新增收款账户（公户/私户）及待收货款。
- 新增独立投资款账页；投资款增加现金和所有者投入，不计入利润。
- 新增“公私互转”账页，用于私户垫款、公户归还垫款和账户调拨；只改变两个账户各自余额，不改变公司总余额或利润。
- 新增“余额明细”账页，分别列出公户和私户每笔流入、流出及逐笔余额，可按日期、账户和业务类型筛选，并可单独导出 Excel。
- “导出全账 Excel”新增余额明细工作表，便于财务核对银行流水和账户余额。
- 办公/其他费用移除“银行手续费”选项，并新增付款来源（公户/私户）。
- 总览和资产负债表分别显示公户、私户与公司合计余额。
- 每次改动先写入本机 IndexedDB，再按顺序同步到 Supabase；断网或云端暂时不可用不会丢失本次录入。
- 网络恢复且应用处于打开状态时自动同步；下次打开应用也会自动补同步。
- 顶部显示云端状态、待同步数量、失败状态，并提供“立即同步”和逐笔“同步详情”。一笔异常记录不会再阻塞其他无关记录。
- 登录和数据请求通过 `ledger.boreviax.com` 的同源路径转发，用户设备不需要直接访问 Supabase 项目域名。
- 登录与 Excel 组件均已保存在项目内，不依赖第三方 CDN 才能启动。
- 在线时每 20 秒自动刷新其他设备提交的数据；本机保存仍会立即同步。
- 支持 RMB / USD、利润表、资产负债表、统计、Excel 和 PDF 导出。
- Admin / Finance / Viewer 权限仍由 Supabase RLS 控制。

## 部署到 GitHub 和 Vercel

1. 解压最终 ZIP。
2. 将里面的文件放到现有 `boreviax-ledger` GitHub 仓库根目录，确保 `index.html` 位于仓库最外层。
3. 用 GitHub Desktop 提交全部变化并 Push origin。
4. 等待 Vercel 显示 Deployment Ready。
5. 用 Chrome 或 Edge 打开正式 HTTPS 网址，联网登录一次，然后点击“安装到桌面”。

本项目是纯静态网页，不需要执行 `npm install`，也不需要设置 Vercel Build Command。

## 从旧版本升级

- Boreviax 正式数据库已完成 V13 字段和同步权限升级；V15 只调整前端网络连接方式，不需要执行新 SQL，直接部署本 ZIP 即可。
- 如果将代码连接到其他 V12 数据库，先在 Supabase SQL Editor 运行一次 `v13_migration.sql`；更早的数据库还需先运行 `v12_migration.sql`。
- 旧采购、来款和费用会自动归为“公户”；私户期初余额默认为 0。
- 数据库中的旧税款字段仅为兼容旧客户端保留，V13 不显示、不写入、不导出，也不参与计算。
- 新 Service Worker 会自动替换旧离线缓存，并且不会缓存登录或财务 API 响应。

## 快速验收

1. 联网登录，确认顶部显示“云端已连接”和“同步正常”。
2. 关闭网络，从桌面图标重新打开应用。
3. 新增、修改或删除一条采购、来款、投资款、公私互转或费用测试记录；记录旁应显示“待同步”。
4. 恢复网络，待同步数量应自动归零；在另一台已登录设备刷新后应能看到改动。

## 注意

- 某台设备第一次使用必须联网登录一次，之后该设备才有本地身份、权限和数据缓存。
- 卸载应用或清除该网站的浏览器数据会删除尚未同步的本地记录；执行前先确认顶部为“同步正常”。
- 多台设备离线修改同一条记录时，最后完成同步的版本会覆盖较早版本。
- 待收货款属于业务跟踪值，在真正到账前不计入现金余额、利润表或资产负债表。
- 公私户互转只在两个账户间移动余额，不计入收入、费用、投资款或利润；两边合计始终为 0。
- 余额明细中的同日记录按录入时间排列；源数据只有日期、没有银行交易时间时，以当天最后一笔后的日终余额为准确核对口径。
- 前端只能使用 Supabase Publishable Key；不要把 Secret Key 或 `service_role` 放入任何网页文件。
- 这是内部管理账本，不等同于审计或报税财务软件。

全新 Supabase 项目才需要运行 `supabase_schema.sql`。
